REST API Reference

Endpoints

  • POST /api/blockchain/register — Register new user (RSA encrypted payload)
  • POST /api/blockchain/transaction — Create transaction between wallets
  • GET /api/blockchain/blocks — View all blocks
  • GET /api/blockchain/report — Generate CSV donation report

Example

curl -X POST http://localhost:8080/api/blockchain/register \
-H "Content-Type: application/json" \
-d '{"username":"Alice","publicKey":""}'
